# EventSphere — Scalable Event Booking Platform

EventSphere is a scalable multi-event booking platform designed to handle high concurrency ticket bookings for **movies, sports, concerts, and large-scale events**. The system focuses on **transaction safety, concurrency control, and scalable backend architecture**, ensuring that seat reservations remain consistent even under heavy traffic.

The platform supports event discovery, seat selection, secure authentication, transactional booking workflows, and administrative management. The architecture is designed to evolve from a **modular monolith into a scalable distributed system**, making it suitable for production-scale environments.

# System Architecture

EventSphere follows a **modular monolith architecture** structured using MVC principles.

```
Client
   ↓
Controller Layer
   ↓
Service Layer
   ↓
Repository Layer
   ↓
Database / Cache
```

Core modules:

* Authentication Module
* Event Management Module
* Booking Module
* Payment Module
* Admin Module

The system is designed so these modules can later be extracted into **independent microservices** if needed.

# Phase 6 — Concurrency-Safe Seat Locking

## Objective

Prevent double booking during high concurrency.

## Implementation

Seat locking using Redis distributed locks.

Example:

```
SET seat:A12 user123 NX EX 300
```

Seat locks automatically expire if booking is not completed.

## Outcome

At the end of this phase:

* Seat locking prevents race conditions
* Double booking is avoided
* Concurrent users can safely reserve seats

# Running the Application

## Clone Repository

```
git clone https://github.com/<your-username>/EventSphere.git
cd EventSphere
```

## Run Application (Development)

```
mvn clean
mvn spring-boot:run
```

Application will run at:

```
http://localhost:8080
```
